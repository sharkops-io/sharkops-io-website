# sharkops-io-website

## Developing sharkops-io-website

### Prerequisites

* NodeJs 10.x or higher (with NPM) - https://nodejs.org/en/download/
* IDE (preferred, VS Code is pretty good, see also: https://marketplace.visualstudio.com/items?itemName=johnpapa.angular-essentials)

### Install NPM dependencies

* Complete the following whenever there are updates to `package.json`
  * `npm install`

### Run the application locally

* `npm run start`
* Navigate to http://localhost:4200 to see the site
* Live Reload is enabled, any change will automatically refresh your browser
