Get started

Charts install straight from the OCI registry, so there is no Helm repository to add.

Install a chart

Each chart's README lists its values and examples.

helm install my-app \
  oci://ghcr.io/sharkops-io/charts/sharkops-universal \
  -f values.yaml

Run an exporter

Each exporter's README lists its settings and metrics.

docker pull ghcr.io/sharkops-io/adguard-exporter:latest

Contributing

All development happens on GitHub. Open an issue to report a bug or suggest a change, or send a pull request. Every pull request runs the project's tests and a secret scan before it can merge.
