Welcome to the SharkOps blog and website. It has been quite some time since I have been able to write like this. The last time was when I was working at Great Lakes, we used Confluence internally and I used to write articles, share opinions, and collaborate with my peers. That collaboration is something that I have been missing recently which is part of why I wanted to start SharkOps.

<!--more-->

The other reason is because I love creating reusable tools that anyone can use and contribute to. My plan is to use SharkOps as a platform to create, share, and collaborate on tools that are useful to anyone in DevOps, Programming, System Administration, etc. I also would like to write tutorials and guides on using the various tools that we use every day. 

Finally, if there is anyone else out there who also feels the same way, please feel free to reach out on Gitter or submit a Merge Request to one of the projects and I would love to have your help sharing with the world. :)
